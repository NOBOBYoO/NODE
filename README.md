# NODE — Settlement Network Dashboard

NODE is an in-game dashboard for Fallout 4 settlement networks, with dedicated Sim Settlements 2 and Workshop Framework integration.

This public repository contains NODE release information and approved downloadable packages only. The project source code is maintained privately and is not distributed from this repository.

## Downloads and information

- [NODE on Nexus Mods](https://www.nexusmods.com/fallout4/mods/107925)
- Approved GitHub packages are published on this repository's Releases page.

Please use the Nexus Mods page for current requirements, installation information, known issues, and support guidance.
